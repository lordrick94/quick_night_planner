**The question, answered from the code.** `/api/generate` builds the
pipeline's argv only from the fields in `GenerateRequest`
(`backend/app.py`). My 2026-11-15 flags (`--placement`, `--previous-plan`,
`--limit`) were not among them, so a GUI plan always got airmass placement
and the default limits. `schedule_before` already worked, because it travels
in the table.

**Fixed.**

  plan under the plans root) and `limits` ({key: number|null}, validated

  pipeline's `supports`). `/api/regenerate` now anchors a Kast re-solve on

install of `~/Projects/night-planner`*, so the `night-planner` console
command, including `night-planner serve`, runs that checkout, which has
none of this work. Serving from this repo with
`python -m uvicorn backend.app:app` picks up the local package. I
smoke-tested that on port 8077: options, the setup controls and the JS all
came through. I did not reinstall anything.
